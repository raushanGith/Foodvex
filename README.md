# Foodvex 🍔

A full-stack food delivery web application that allows users to browse restaurants, manage their cart, and track orders. It features a custom "Neo-Tactile" CSS design and a robust Java backend.

## 🚀 Features
* **User Authentication:** Secure login, registration, and profile management.
* **Restaurant & Menu Browsing:** Dynamic loading of restaurants and their specific menus.
* **Cart Management:** Add, edit, and remove items before checkout.
* **Order Processing:** Secure checkout and comprehensive order history tracking.
* **Admin Dashboard:** Centralized control for managing menus, restaurants, and order statuses.

## 🛠️ Tech Stack
* **Backend:** Java Servlets, JSP (JavaServer Pages)
* **Database:** MySQL with DAO (Data Access Object) design pattern
* **Frontend:** HTML5, Custom Neo-Tactile CSS Engine
* **Environment:** Apache Tomcat, Eclipse IDE
